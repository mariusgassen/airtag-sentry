# AirTagSentry dashboard (frontend)

Vite + React + TypeScript PWA for the AirTagSentry dashboard. See the
repo root [README](../README.md) — sections "Development" and "Database
migrations" — for the full setup, dev server, and build instructions.

Quick reference:

```bash
npm install
npm run dev     # dev server on :5173, proxies /api etc. to :8000
npm run build   # writes into ../airtag_sentry/web/static
```
